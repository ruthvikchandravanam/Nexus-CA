Below is the by-feature catalogue — every screen in Docs/1-Requirements/ui-screens.md, styled to branding.md. Click any tile to open the full screen. No build step — these are static files; open in a browser.

Action screens carry a “View as” role switcher (top-right). Switch between the 5 roles to see exactly which buttons, nav items and pages each role is permitted, per BRD §Permissions — e.g. an AUDITOR loses every action, OPERATORs cannot open Users / System Configuration, and only ADMIN_MAKER sees Create / Revoke / Edit.
