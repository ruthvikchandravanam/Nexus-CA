Nexus CA — Role Personas

What each of the five roles sees and does. Built from BRD §Roles, §Permissions and §Request Visibility.
← Feature catalogue (all 32 screens)

Each persona below links to a role-correct dashboard and that role's signature screens — note how the navigation sidebar and the available actions change per role. The maker/checker split is enforced: makers cannot see the approval queue; only checkers and the auditor do.

AM

ADMIN_MAKER

Initiator · Admin

Initiates administrative requests: CA management, user management, certificate revocation, and system configuration.

  • ✓ Create / Enable-Disable / Revoke Root & Intermediate CAs
  • ✓ Create users, assign roles, reset passwords
  • ✓ Create / edit / delete custom roles (RBAC engine)
  • ✓ Edit System Configuration (submits change request)
  • ✗ Cannot approve — no approval queue in nav
Dashboard Create Root CA Create Intermediate CA Manage Roles System Config My Requests
AC

ADMIN_CHECKER

Approver · Admin

Reviews and approves or rejects administrative requests submitted by ADMIN_MAKER.

  • ✓ Approve / Reject CA, user, role, revocation & config requests
  • ✓ View all administrative requests & field-level diffs
  • ✗ Cannot initiate requests or edit configuration
  • ✗ Cannot approve a request they submitted (self-approval blocked)
Dashboard Approval Queue Review Request
OM

OPERATOR_MAKER

Initiator · Operations

Submits certificate issuance requests and downloads the issued certificate.

  • ✓ Submit CSR for CLIENT / SERVER / SIGNING issuance
  • ✓ Download issued certificate (first download → COMPLETED)
  • ✗ No Users or System Configuration in nav
  • ✗ Cannot approve — no approval queue in nav
Dashboard Submit CSR Download Cert My Requests
OC

OPERATOR_CHECKER

Approver · Operations

Reviews and approves or rejects certificate issuance requests.

  • ✓ Approve / Reject certificate issuance requests
  • ✓ View CSR detail, chosen CA, type, validity, output format
  • ✓ May download issued certificate (does not trigger COMPLETED)
  • ✗ No Users or System Configuration in nav
Dashboard Issuance Queue Review Issuance
AU

AUDITOR

Read-only · Compliance

Read-only access to all data across the platform for compliance and audit purposes.

  • ✓ View every CA, certificate, user, request & report
  • ✓ View all requests of all types (read-only)
  • ✓ Full audit log access
  • ✗ No create, edit, approve, or download actions anywhere
Dashboard Read-only Request Audit Log
